Lokale Bedienhilfe und ein bearbeitbarer Entwurf der Erklärung zur Barrierefreiheit.

== Description ==

MGD Barrierefrei ergänzt WordPress um ein konfigurierbares, tastaturbedienbares Modal für Darstellungspräferenzen und einen Generator für eine Erklärung zur Barrierefreiheit.

Die Bedienhilfe ersetzt weder eine barrierefreie Website noch eine Prüfung mit echten Nutzerinnen und Nutzern. Der erzeugte Erklärungstext bleibt ein Entwurf und muss vor einer Veröffentlichung geprüft werden.

Besucherpräferenzen bleiben im localStorage des jeweiligen Browsers. Es gibt kein Besuchertracking und keine externen Schriften oder Skripte.

Diese GitHub-Ausgabe verwendet öffentliche GitHub-Release-Metadaten für Updates und den öffentlichen Katalog von theme.michael-gahn.de für Empfehlungen im Backend. Die Darstellung und sieben passende Icons und Hintergrundbilder sind lokal enthalten. Es wird kein ausführbarer Code nachgeladen. Installation und Aktualisierung verlangen eine ausdrückliche Verwaltungsaktion. Diese Ausgabe ist kein WordPress.org-Einreichungspaket.

== Installation ==

1. mgd-barrierefrei-wordpress.zip aus dem GitHub-Release herunterladen.
2. In WordPress unter Plugins > Installieren > Plugin hochladen installieren und aktivieren.
3. MGD Barrierefrei im Menü öffnen, Darstellung und Kontaktangaben eintragen.
4. Den erzeugten Seitenentwurf inhaltlich prüfen und erst anschließend veröffentlichen.
