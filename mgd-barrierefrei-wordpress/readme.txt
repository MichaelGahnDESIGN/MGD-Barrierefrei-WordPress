Local reading preferences and editable draft accessibility statements.

== Description ==

Local reading preferences and editable draft accessibility statements.

Features:

* Offer contrast, grayscale, focus, text size, readable text, link emphasis and reduced-motion preferences.
* Store visitor preferences on the device without analytics.
* Configure the panel label, position and accent color.
* Collect organization, responsible person, contact information, known barriers and statement date.
* Create a page draft for review; the plugin does not automatically publish a compliance claim.

This edition uses native WordPress.org updates. There is no GitHub self-updater or external plugin installer. Updates become available after approval and publication in the directory.

Documentation and source: https://github.com/MichaelGahnDESIGN/MGD-Barrierefrei-WordPress

Reading preferences do not repair content or certify legal compliance. Review the generated statement before publishing. The manufacturer credit is optional and off by default.

== Installation ==

1. Upload the plugin folder or install the approved directory release from Plugins > Add New.
2. Activate the plugin and review its settings.
3. Test the configured features before enabling them on a production website.

== Frequently Asked Questions ==

= How are updates delivered? =
WordPress checks the official directory. This edition has no configurable update repository.

= Does it send analytics? =
No analytics or telemetry service is included. WordPress communicates with WordPress.org for native updates. Support links open only when clicked.
